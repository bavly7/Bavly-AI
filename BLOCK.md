# BLOCK.md — Active Blockers & Struggles

> Live log of anything an agent gets stuck on: errors, failed fetches,
> ambiguous specs, bugs requiring investigation, unclear instructions.
>
> RULE: when an entry is resolved, DELETE it from this file — don't mark
> it done, remove it. This file should be empty or near-empty most of the
> time. If it's growing and not shrinking, that's a signal something
> structural is wrong, not just a string of bad luck.
>
> Format per entry:
> ```
> ## [date] short title
> - What was attempted:
> - What happened / error:
> - Status: investigating / needs owner input / blocked on external service
> ```
