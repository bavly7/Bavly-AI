# Tips Hindawy — Overview

**Program:** AI Agents & LLMs — Hands-On Training
**Status:** IN PROGRESS (not yet completed)

A practical, project-based training program covering AI agent and LLM
fundamentals, prompt engineering, Retrieval-Augmented Generation (RAG),
and building AI-powered applications — from foundational concepts to
production-ready systems.

- Retrieval-Augmented Generation (RAG) & embeddings
- Fine-tuning basics & model optimization
- Working with tools like LangChain & vector databases
- Real-world projects & use cases
