# DEPI — Learnings

Mastered an end-to-end data pipeline, starting from web scraping using
BeautifulSoup4 (bs4), through data handling and manipulation with Pandas,
to data visualization using Seaborn and Matplotlib.

Gained comprehensive hands-on experience with classical Machine Learning
algorithms, including Linear and Logistic Regression, SVM, Decision Trees,
clustering methods, and ensemble methods like XGBoost — comparing
different approaches against each other to identify what worked best for
a given problem.

Rounded out the program with foundational knowledge in MLOps practices for
model deployment.
