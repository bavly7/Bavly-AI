# KYC Onboarding System — Learnings

This project fundamentally changed how Bavly approaches system
orchestration. It gave him a much deeper, hands-on understanding of
LangGraph — specifically how to structure states, nodes, and edges to
maintain control over an agent's reasoning through a non-linear process.

He moved from understanding AI agents as single-shot responders (ask a
question, get an answer) to building complex, stateful execution graphs
that can loop, branch, and route based on intermediate results — a
meaningfully different way of thinking about how an "agent" actually
works in a real system.
