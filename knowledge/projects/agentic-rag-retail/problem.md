# Agentic RAG Retail Analytics — Problem

Store managers typically have to manually navigate separate dashboards to
understand customer behavior (foot traffic, dwell time, occupancy) and
separately model out hypothetical business decisions (like "what if I
discount this category?"). These are usually disconnected tools and
require the manager to do the cross-referencing themselves.

This system solves that by unifying live CV-derived analytics,
documentation/knowledge retrieval, and sales forecasting behind a single
conversational interface — so a manager can ask a natural-language
business question and get a synthesized answer that pulls from whichever
underlying source (or combination of sources) the question actually
needs.
