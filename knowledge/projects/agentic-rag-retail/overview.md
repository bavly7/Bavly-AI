# Agentic RAG Retail Analytics — Overview

An end-to-end retail analytics system that combines Computer Vision,
Agentic RAG, and Machine Learning to let supermarket managers query live
customer-behavior data and sales forecasts in natural language, instead of
navigating dashboards. A manager can ask things like "which section has
the highest traffic right now?" or "what if we apply a 15% discount every
Thursday?" and get an answer generated by an AI assistant that combines
live computer vision analytics, retrieval-augmented generation, and ML
forecasting.

**GitHub:** `Agentic-RAG-Retail-Assistant`
**Tech stack:** YOLO, Llama-3 (Groq), LangChain, LightGBM, Qdrant, OpenCV,
Hugging Face Embeddings, Streamlit, LangSmith
