# Agentic RAG Retail Analytics — Learnings

This project fundamentally changed Bavly's perspective from "building
isolated models" to "building cohesive products." It taught him how to
orchestrate entirely different AI domains — Computer Vision (YOLO) and
classical Machine Learning (LightGBM) — under a single LLM agent umbrella
(LangChain/Groq), to create one unified, interactive business tool that
provides real value, rather than several disconnected demos.
